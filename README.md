# Python Learning

个人 Python 学习与练习代码仓库。

本仓库用于记录 Python 学习过程中的课程代码、小作业、算法练习以及阶段性项目。

## 内容

目前仓库主要包括以下几类内容：

### 课程练习

按照学习周次整理的 Python 练习代码，例如：

- 第三周
- 第四周
- 第五周
- 第六周
- 第七周

涉及 Python 基础语法、数据结构、函数、递归以及基本程序设计等内容。

### 小作业

仓库中包含多个阶段性小作业，例如：

- Hanoi 相关递归练习
- 素数查找与运行时间比较
- 字符串处理
- 基础数据处理

### 矩阵项目

仓库还包含一个矩阵相关的课程项目，实现了自定义的矩阵数据结构及相关操作，并提供对应的测试程序。

项目目录中包括：

```text
final project/
├── main.py
└── minimatrix.py
```

## 使用方式

大部分代码可以直接使用 Python 运行：

```bash
python 文件名.py
```

部分代码使用了 NumPy 等第三方库，需要根据具体文件安装相应依赖。

## 说明

这是个人学习代码仓库，主要用于课程学习、练习和代码归档。

仓库中的部分文件属于课堂练习或实验性代码，不以生产环境使用为目标。
